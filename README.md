# Sistema de productos

Aplicación desarrollada con Django para registrar y listar productos de una tienda y que queden guardados en una base de datos

## Tecnologías
- Python
- Django
- SQLite
- HTML
- Git y GitHub

## Ejecute
1. Cree y active el entorno virtual.
2. Instale Django: `pip install django`
3. Ejecute las migraciones: `python manage.py migrate`
4. Ejecute el servidor: `python manage.py runserver`

## Funcionalidad de la app
- Registrar nuevos productos a través de un formulario web.
- Listar todos los productos registrados en una tabla HTML.
